# RAG-Semiconductor-KnowledgeBase

基于 RAG（Retrieval-Augmented Generation）的半导体领域智能知识库系统。

## 项目介绍

本项目针对大语言模型在专业领域应用过程中存在的知识更新滞后、领域知识不足以及回答幻觉等问题，设计并实现了一套面向半导体领域的智能知识库系统。系统以半导体技术论文、行业研报等专业文档作为知识来源，通过自动化文档解析、语义切片、向量化存储、混合检索以及 Agent 推理流程，实现对专业知识的高效检索和可信生成。

系统整体采用 Python 作为开发语言，结合 LangChain、LangGraph、Milvus、BGE Embedding、BM25 以及 DeepSeek-V3 等技术，实现完整的 RAG 应用链路，包括数据处理层、知识存储层、检索增强层以及智能问答层。

## 项目功能

### 1. 文档解析与知识库构建

系统支持对 PDF、Markdown、Word、HTML 等非结构化文档进行解析，将原始文件转换为可检索的知识单元。

在文档处理阶段：

- 使用 PyMuPDF 对 PDF 文档进行解析；
- 使用 UnstructuredLoader 对复杂结构文档进行加载；
- 使用 OCR 技术提取图片中的文字信息；
- 根据文档标题层级恢复上下文结构；
- 使用 Semantic Chunking 方法进行语义切片。

相比传统基于固定长度的文本切割方式，语义切片能够根据内容语义变化进行分割，减少重要信息被截断的问题，提高后续检索阶段的上下文完整性。

## 2. Milvus 混合检索系统

为了提升专业领域知识检索效果，系统构建了 Dense + Sparse 的混合检索架构。

其中：

Dense Retrieval：

- 使用 BGE-large-zh-v1.5 生成文本向量；
- 使用 Milvus HNSW 索引进行向量相似度搜索；
- 用于捕获文本之间的语义关联。


Sparse Retrieval：

- 使用 BM25 算法建立关键词检索能力；
- 使用倒排索引提高专业术语匹配能力；
- 用于处理半导体领域中的精确关键词查询。


最终通过 RRF（Reciprocal Rank Fusion）方法融合两类检索结果，使系统同时具备：

- 语义理解能力；
- 专业术语匹配能力；
- 更高的知识召回能力。


## 3. 基于 LangGraph 的 Agent 工作流

系统基于 LangGraph 构建 Agent 化 RAG 工作流，将传统固定流程升级为动态决策流程。

Agent 根据用户问题自动判断：

- 是否需要调用知识库检索；
- 是否需要访问外部搜索；
- 是否需要重新优化查询。

## 4. Corrective RAG

针对传统 RAG 中检索结果可能与用户问题不相关的问题，系统引入 Corrective RAG 机制。

在生成答案之前增加文档评估环节：

1. 检索候选文档；
2. 使用 LLM 判断文档与问题的相关性；
3. 保留有效知识；
4. 对低质量检索结果进行 Query Rewrite；
5. 重新执行检索流程。

的闭环流程，提高生成结果可靠性。

## 6. 高性能数据处理

针对大量文档入库场景，系统设计生产者-消费者多进程架构。

其中：

生产者：

- 扫描文档目录；
- 执行文档解析；
- 完成文本切片；
- 批量发送任务。


消费者：

- 从队列读取文档；
- 调用 Milvus 接口；
- 完成向量化和数据库写入。


通过多进程方式降低文档处理阻塞，提高大规模知识库构建效率。
